# Mzansi Learning Hub

Lightweight, offline-first LMS control layer for Marc Diedricks' learning PWAs.

## Current phase
Phase 0.1A — LMS Shell

## Pilot programme
Mzansi Boilermaker — UMLA Learning Record v0.1

## Current scope
- Home
- My Learning
- Programmes
- Progress
- Profile
- offline app shell
- mobile-first interface
- one Boilermaker pilot programme registry entry

## Important
The specialist PWAs remain the learning engines. The Learning Hub does not duplicate course content.

Phase 0.1B will prove a local UMLA handoff/import bridge before any cloud sync is introduced.
